**漂亮的页面不能替代证据。** 这个示例只验证 Markdown 如何呈现为 HTML，不声称任何研究结论已被证实。[1]

## 引用与代码

正文中的编号可跳转到文末来源；连续来源条目应逐条换行。[1][2]

但内联代码 `[1]` 和下面代码块里的编号应保留原样，不应变成引用链接：

```python
# 仅展示文本，不执行。
example = "[1] 保留代码内容"
```

## 待验证项

- 手机宽度下正文不应产生整页横向溢出。
- 宽表格应在自己的区域内滚动。
- 目录、引用与附页锚点应指向实际存在的位置。
- 原始 Markdown 不应被修改。
